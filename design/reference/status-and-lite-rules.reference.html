Lite mode turns on by itself

Solid panels, no blur, fewer moving parts. Any one of these switches it on:

  • Screen 1440 px wide or less, or 800 px tall or less
  • 4 CPU cores or fewer, or 4 GB memory or less
  • The map drops below 30 frames a second for 3 seconds
  • Windows "transparency effects" or reduced motion is off / on

The user can still switch it with the Lite mode toggle, and the choice is remembered. In lite mode the AI team folds into an icon rail and "Needs you" shows the top 2.
